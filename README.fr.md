### 1. Présentation du projet

- **🍹 [beverage.wiki](https://beverage.wiki/) est une encyclopédie ouverte des boissons**, documentant l'histoire, les recettes, l'emballage et la culture des boissons du monde entier.
- **📖 Tout le contenu est rédigé en Markdown et hébergé sur GitHub ; chacun peut contribuer.**
- **🧃 Les boissons ne sont pas de simples produits — elles portent la culture, la mémoire et l'émotion.**
- **🛠 Entièrement open source. Forks, Stars, PR, suggestions et discussions sont bienvenus.**

### 2. Comment contribuer

#### ✅ Étape 1 : Vérifier les entrées existantes

Avant de soumettre, parcourez le dossier `/drinks` pour vérifier que la boisson n'existe pas déjà.

#### 📄 Étape 2 : Préparer votre entrée

- Chaque boisson a un fichier Markdown par langue dans `/drinks`.
- Format de nommage : `nom-boisson.locale.md`, par exemple :
  - `CocaCola_Can_330ml.fr.md` (français)
- Codes de locale supportés : `zh`, `en`, `ja`, `ko`, `fr`, `de`, `es`, `pt`, `ru`, `ar`, `hi`, `th`, `vi`, etc.
- Pas besoin de traduire. Soumettez uniquement les langues que vous maîtrisez.
- Consultez le dossier `/example` pour les modèles.

#### 🔧 Étape 3 : Soumettre une Pull Request

1. Forkez ce dépôt.
2. Créez une nouvelle branche (ex. `add-pepsi-blue`).
3. Ajoutez/modifiez les fichiers Markdown dans `/drinks`.
4. Poussez et ouvrez une Pull Request.

### 🖼 Ajouter des images

#### ✅ Option 1 : Lier une image web

```text
https://example.com/images/coca-cola-can.jpg
```

#### ✅ Option 2 : Téléverser dans le dépôt

Placez les images dans `/public/images` et référez-les par un chemin relatif :

```text
/images/CocaCola_Can_330ml_pour.jpg
```

> ⚠️ Utilisez le schéma : marque + spécification + action
