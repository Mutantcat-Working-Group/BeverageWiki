### 1. Project Overview

- **🍹 [beverage.wiki](https://beverage.wiki/) is an open beverage encyclopedia** documenting the history, recipes, packaging, and culture of drinks from around the world.
- **📖 All content is written in Markdown and hosted on GitHub; anyone can contribute.**
- **🧃 Beverages are not just products—they carry culture, memory, and emotion.**
- **🛠 Open source. We welcome Forks, Stars, PRs, suggestions, and discussions.**

### 2. How to Contribute

#### ✅ Step 1: Check for Existing Entries

Before submitting, browse the `/drinks` folder to confirm the drink isn't already present.

#### 📄 Step 2: Prepare Your Entry

- Each drink has one Markdown file per language, placed in `/drinks`.
- File naming format: `drink-name.locale.md`, for example:
  - `CocaCola_Can_330ml.zh.md` (Chinese)
  - `CocaCola_Can_330ml.en.md` (English)
- Supported locale codes: `zh`, `en`, `ja`, `ko`, `fr`, `de`, `es`, `pt`, `ru`, `ar`, `hi`, `th`, `vi`, etc.
- You only need to submit the language(s) you know—no full translation required.
- Use `/example` folder files as templates.

#### 🔧 Step 3: Submit a Pull Request

1. Fork this repo.
2. Create a new branch (e.g., `add-pepsi-blue`).
3. Add or modify Markdown files under `/drinks`.
4. Commit, push, and open a Pull Request.

### 🖼 Adding Images

#### ✅ Option 1: Link an Image on the Web

```text
https://example.com/images/coca-cola-can.jpg
```

#### ✅ Option 2: Upload to the Repository

Place image files under `/public/images` and reference via a relative path:

```text
/images/CocaCola_Can_330ml_pour.jpg
```

> ⚠️ Use naming pattern: brand + spec + action, e.g., `Pepsi_Blue_Bottle_500ml_front.jpg`
