### 1. 프로젝트 개요

- **🍹 [beverage.wiki](https://beverage.wiki/)는 전 세계 음료의 역사, 레시피, 포장, 문화를 기록하는 오픈 음료 백과사전입니다.**
- **📖 모든 콘텐츠는 Markdown으로 작성되어 GitHub에서 호스팅됩니다. 누구나 기여할 수 있습니다.**
- **🧃 음료는 단순한 상품이 아니라 문화, 기억, 감정의 매개체입니다.**
- **🛠 완전 오픈소스. Fork·Star·PR·제안·토론을 환영합니다.**

### 2. 기여 방법

#### ✅ 1단계: 기존 항목 확인

제출하기 전에 리포지토리의 `/drinks` 폴더를 확인하세요.

#### 📄 2단계: 항목 준비

- 각 음료는 언어별로 별도의 Markdown 파일을 `/drinks`에 배치
- 파일 이름 형식: `음료이름.로케일.md` (예: `CocaCola_Can_330ml.ko.md`)
- 지원 로케일: `zh`, `en`, `ja`, `ko`, `fr`, `de`, `es`, `pt`, `ru`, `ar`, `hi`, `th`, `vi` 등
- 번역이 필요하지 않습니다. 알고 있는 언어만 제출하세요.
- 포맷은 `/example` 폴더를 참조

#### 🔧 3단계: Pull Request 제출

1. 리포지토리를 Fork
2. 새 브랜치 생성 (예: `add-pepsi-blue`)
3. `/drinks`에 Markdown 추가/수정
4. 커밋, 푸시, PR 열기

### 🖼 이미지 추가 방법

#### ✅ 방법 1: 웹 이미지 링크

```text
https://example.com/images/coca-cola-can.jpg
```

#### ✅ 방법 2: 리포지토리에 업로드

`/public/images`에 이미지를 배치하고 상대 경로로 참조:

```text
/images/CocaCola_Can_330ml_pour.jpg
```

> ⚠️ 파일 이름 패턴: 브랜드명 + 스펙 + 동작
