### 1. Обзор проекта

- **🍹 [beverage.wiki](https://beverage.wiki/) — открытая энциклопедия напитков**, документирующая историю, рецепты, упаковку и культуру напитков со всего мира.
- **📖 Весь контент написан на Markdown и размещён на GitHub; любой может внести вклад.**
- **🧃 Напитки — не просто продукты, они несут в себе культуру, память и эмоции.**
- **🛠 Полностью открытый исходный код. Приветствуются форки, звёзды, PR, предложения и обсуждения.**

### 2. Как внести вклад

#### ✅ Шаг 1: Проверить существующие записи

Перед отправкой просмотрите папку `/drinks`, чтобы убедиться, что напитка ещё нет.

#### 📄 Шаг 2: Подготовить запись

- Каждый напиток имеет отдельный Markdown-файл для каждого языка в `/drinks`.
- Формат имени: `название-напитка.locale.md`, например:
  - `CocaCola_Can_330ml.ru.md` (русский)
- Поддерживаемые коды локалей: `zh`, `en`, `ja`, `ko`, `fr`, `de`, `es`, `pt`, `ru`, `ar`, `hi`, `th`, `vi` и др.
- Полный перевод не обязателен. Отправляйте только те языки, которые знаете.
- Шаблоны в папке `/example`.

#### 🔧 Шаг 3: Отправить Pull Request

1. Форкните репозиторий.
2. Создайте новую ветку (например, `add-pepsi-blue`).
3. Добавьте/измените Markdown-файлы в `/drinks`.
4. Закоммитьте, запушьте и откройте PR.

### 🖼 Добавление изображений

#### ✅ Вариант 1: Ссылка на веб-изображение

```text
https://example.com/images/coca-cola-can.jpg
```

#### ✅ Вариант 2: Загрузка в репозиторий

Разместите изображения в `/public/images` и укажите относительный путь:

```text
/images/CocaCola_Can_330ml_pour.jpg
```

> ⚠️ Схема именования: бренд + характеристика + действие
