### 1. Projektübersicht

- **🍹 [beverage.wiki](https://beverage.wiki/) ist ein offenes Getränke-Lexikon**, das Geschichte, Rezepte, Verpackung und Kultur von Getränken aus aller Welt dokumentiert.
- **📖 Alle Inhalte sind in Markdown verfasst und auf GitHub gehostet; jeder kann beitragen.**
- **🧃 Getränke sind nicht nur Produkte — sie tragen Kultur, Erinnerung und Emotion in sich.**
- **🛠 Völlig Open Source. Forks, Stars, PRs, Vorschläge und Diskussionen sind willkommen.**

### 2. So tragen Sie bei

#### ✅ Schritt 1: Vorhandene Einträge prüfen

Durchsuchen Sie vor dem Einreichen den Ordner `/drinks`, um sicherzustellen, dass das Getränk noch nicht vorhanden ist.

#### 📄 Schritt 2: Eintrag vorbereiten

- Jedes Getränk hat eine Markdown-Datei pro Sprache in `/drinks`.
- Dateinamensformat: `getränkename.locale.md`, z. B.:
  - `CocaCola_Can_330ml.de.md` (Deutsch)
- Unterstützte Locale-Codes: `zh`, `en`, `ja`, `ko`, `fr`, `de`, `es`, `pt`, `ru`, `ar`, `hi`, `th`, `vi` usw.
- Keine vollständige Übersetzung erforderlich — reichen Sie nur Sprachen ein, die Sie beherrschen.
- Vorlagen im Ordner `/example`.

#### 🔧 Schritt 3: Pull Request einreichen

1. Repository forken.
2. Neuen Branch erstellen (z. B. `add-pepsi-blue`).
3. Markdown-Dateien in `/drinks` hinzufügen/ändern.
4. Committen, pushen und PR öffnen.

### 🖼 Bilder hinzufügen

#### ✅ Option 1: Web-Bilder verlinken

```text
https://example.com/images/coca-cola-can.jpg
```

#### ✅ Option 2: In das Repository hochladen

Bilder in `/public/images` ablegen und per relativem Pfad referenzieren:

```text
/images/CocaCola_Can_330ml_pour.jpg
```

> ⚠️ Benennungsschema: Marke + Spezifikation + Aktion
