### 1. Descripción del proyecto

- **🍹 [beverage.wiki](https://beverage.wiki/) es una enciclopedia abierta de bebidas** que documenta la historia, recetas, empaques y cultura de bebidas de todo el mundo.
- **📖 Todo el contenido está escrito en Markdown y alojado en GitHub; cualquiera puede contribuir.**
- **🧃 Las bebidas no son solo productos — llevan cultura, memoria y emoción.**
- **🛠 Totalmente de código abierto. Se aceptan Forks, Stars, PRs, sugerencias y discusiones.**

### 2. Cómo contribuir

#### ✅ Paso 1: Verificar entradas existentes

Antes de enviar, revise la carpeta `/drinks` para confirmar que la bebida no existe.

#### 📄 Paso 2: Preparar su entrada

- Cada bebida tiene un archivo Markdown por idioma en `/drinks`.
- Formato de nombre: `nombre-bebida.locale.md`, por ejemplo:
  - `CocaCola_Can_330ml.es.md` (español)
- Códigos de locale soportados: `zh`, `en`, `ja`, `ko`, `fr`, `de`, `es`, `pt`, `ru`, `ar`, `hi`, `th`, `vi`, etc.
- No necesita traducir todo. Envíe solo los idiomas que conoce.
- Consulte la carpeta `/example` para plantillas.

#### 🔧 Paso 3: Enviar un Pull Request

1. Haga fork de este repositorio.
2. Cree una nueva rama (ej. `add-pepsi-blue`).
3. Agregue/modifique archivos Markdown en `/drinks`.
4. Haga commit, push y abra un PR.

### 🖼 Agregar imágenes

#### ✅ Opción 1: Enlazar una imagen web

```text
https://example.com/images/coca-cola-can.jpg
```

#### ✅ Opción 2: Subir al repositorio

Coloque las imágenes en `/public/images` y referéncielas con una ruta relativa:

```text
/images/CocaCola_Can_330ml_pour.jpg
```

> ⚠️ Patrón de nombres: marca + especificación + acción
