### 1. Visão geral do projeto

- **🍹 [beverage.wiki](https://beverage.wiki/) é uma enciclopédia aberta de bebidas** que documenta a história, receitas, embalagens e cultura de bebidas do mundo inteiro.
- **📖 Todo o conteúdo é escrito em Markdown e hospedado no GitHub; qualquer pessoa pode contribuir.**
- **🧃 Bebidas não são apenas produtos — carregam cultura, memória e emoção.**
- **🛠 Totalmente open source. Forks, Stars, PRs, sugestões e discussões são bem-vindos.**

### 2. Como contribuir

#### ✅ Passo 1: Verificar entradas existentes

Antes de enviar, verifique a pasta `/drinks` para confirmar que a bebida ainda não existe.

#### 📄 Passo 2: Preparar sua entrada

- Cada bebida tem um arquivo Markdown por idioma em `/drinks`.
- Formato do nome: `nome-da-bebida.locale.md`, por exemplo:
  - `CocaCola_Can_330ml.pt.md` (português)
- Códigos de locale suportados: `zh`, `en`, `ja`, `ko`, `fr`, `de`, `es`, `pt`, `ru`, `ar`, `hi`, `th`, `vi`, etc.
- Não precisa traduzir tudo. Envie apenas os idiomas que conhece.
- Consulte a pasta `/example` para modelos.

#### 🔧 Passo 3: Enviar um Pull Request

1. Faça fork deste repositório.
2. Crie uma nova branch (ex. `add-pepsi-blue`).
3. Adicione/modifique arquivos Markdown em `/drinks`.
4. Faça commit, push e abra um PR.

### 🖼 Adicionar imagens

#### ✅ Opção 1: Vincular uma imagem da web

```text
https://example.com/images/coca-cola-can.jpg
```

#### ✅ Opção 2: Enviar para o repositório

Coloque as imagens em `/public/images` e referencie com caminho relativo:

```text
/images/CocaCola_Can_330ml_pour.jpg
```

> ⚠️ Padrão de nomenclatura: marca + especificação + ação
