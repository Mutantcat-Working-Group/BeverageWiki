### 1. परियोजना अवलोकन

- **🍹 [beverage.wiki](https://beverage.wiki/) एक खुला पेय पदार्थ विश्वकोश है** जो दुनिया भर के पेय पदार्थों के इतिहास, व्यंजनों, पैकेजिंग और संस्कृति का दस्तावेजीकरण करता है।
- **📖 सभी सामग्री Markdown में लिखी गई है और GitHub पर होस्ट की गई है; कोई भी योगदान कर सकता है।**
- **🧃 पेय पदार्थ केवल उत्पाद नहीं हैं — वे संस्कृति, स्मृति और भावना लेकर चलते हैं।**
- **🛠 पूर्णतः ओपन सोर्स। Fork, Star, PR, सुझाव और चर्चाओं का स्वागत है।**

### 2. योगदान कैसे करें

#### ✅ चरण 1: मौजूदा प्रविष्टियाँ जाँचें

जमा करने से पहले, `/drinks` फ़ोल्डर देखें।

#### 📄 चरण 2: अपनी प्रविष्टि तैयार करें

- प्रत्येक पेय पदार्थ की प्रत्येक भाषा के लिए एक अलग Markdown फ़ाइल `/drinks` में रखें।
- फ़ाइल नाम प्रारूप: `पेय-नाम.locale.md`, उदाहरण:
  - `CocaCola_Can_330ml.hi.md` (हिन्दी)
- समर्थित लोकेल कोड: `zh`, `en`, `ja`, `ko`, `fr`, `de`, `es`, `pt`, `ru`, `ar`, `hi`, `th`, `vi` आदि।
- पूर्ण अनुवाद की आवश्यकता नहीं। केवल वे भाषाएँ जमा करें जो आप जानते हैं।
- टेम्पलेट के लिए `/example` फ़ोल्डर देखें।

#### 🔧 चरण 3: Pull Request सबमिट करें

1. इस रिपॉजिटरी को Fork करें।
2. नई ब्रांच बनाएं (जैसे `add-pepsi-blue`)।
3. `/drinks` में Markdown जोड़ें/संशोधित करें।
4. कमिट, पुश करें और PR खोलें।
