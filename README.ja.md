### 1. プロジェクト概要

- **🍹 [beverage.wiki](https://beverage.wiki/) はオープンな飲料百科事典プロジェクトです。** 世界中の飲料の歴史、レシピ、パッケージ、文化を記録しています。
- **📖 すべてのコンテンツは Markdown で書かれ、GitHub でホストされています。誰でも投稿できます。**
- **🧃 飲料は単なる商品ではなく、文化・記憶・感情の载体です。**
- **🛠 完全オープンソース。Fork・Star・PR・提案・ディスカッションを歓迎します。**

### 2. 貢献方法

#### ✅ ステップ1：既存エントリを確認

投稿前にリポジトリの `/drinks` フォルダを確認してください。

#### 📄 ステップ2：エントリを準備

- 各飲料は言語ごとに個別の Markdown ファイルを `/drinks` に配置
- ファイル命名：`ドリンク名.ロケール.md`（例：`CocaCola_Can_330ml.ja.md`）
- 対応ロケールコード：`zh`、`en`、`ja`、`ko`、`fr`、`de`、`es`、`pt`、`ru`、`ar`、`hi`、`th`、`vi` など
- 翻訳は不要。知っている言語だけ投稿してください。
- フォーマットは `/example` フォルダを参照

#### 🔧 ステップ3：Pull Request を送信

1. リポジトリを Fork
2. 新しいブランチを作成（例：`add-pepsi-blue`）
3. `/drinks` に Markdown を追加・編集
4. コミット・プッシュして PR を作成

### 🖼 画像の追加方法

#### ✅ 方法1：ウェブ画像をリンク

```text
https://example.com/images/coca-cola-can.jpg
```

#### ✅ 方法2：リポジトリにアップロード

`/public/images` に画像を配置し、相対パスで参照：

```text
/images/CocaCola_Can_330ml_pour.jpg
```

> ⚠️ ファイル名は「ブランド名＋スペック＋動作」のパターン推奨
