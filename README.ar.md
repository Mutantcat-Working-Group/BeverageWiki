### 1. نظرة عامة على المشروع

- **🍹 [beverage.wiki](https://beverage.wiki/) هو موسوعة مشروبات مفتوحة** يوثق تاريخ ووصفات وتعبئة وثقافة المشروبات من جميع أنحاء العالم.
- **📖 كل المحتوى مكتوب بصيغة Markdown ويستضاف على GitHub؛ يمكن لأي شخص المساهمة.**
- **🧃 المشروبات ليست مجرد منتجات — إنها تحمل الثقافة والذاكرة والعاطفة.**
- **🛠 مفتوح المصدر بالكامل. نرحب بالフォーكات والنجوم وطلبات السحب والاقتراحات والمناقشات.**

### 2. كيفية المساهمة

#### ✅ الخطوة 1: التحقق من الإدخالات الموجودة

قبل الإرسال، تصفح مجلد `/drinks` للتأكد من عدم وجود المشروب بالفعل.

#### 📄 الخطوة 2: تحضير الإدخال

- كل مشروب يحتوي على ملف Markdown لكل لغة في `/drinks`.
- صيغة تسمية الملف: `اسم-المشروب.locale.md`، مثال:
  - `CocaCola_Can_330ml.ar.md` (العربية)
- أكواد اللغات المدعومة: `zh`, `en`, `ja`, `ko`, `fr`, `de`, `es`, `pt`, `ru`, `ar`, `hi`, `th`, `vi` وغيرها.
- لا حاجة للترجمة الكاملة. أرسل فقط اللغات التي تعرفها.
- استخدم مجلد `/example` كنموذج.

#### 🔧 الخطوة 3: إرسال Pull Request

1. قم بعمل Fork لهذا المستودع.
2. أنشئ فرعًا جديدًا (مثال: `add-pepsi-blue`).
3. أضف/عدّل ملفات Markdown في `/drinks`.
4. قم بالالتزام والدفع وافتح طلب سحب.
